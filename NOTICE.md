# Third-party material

Shield by VPNInsights is made by VPNInsights. The code is released under the MIT licence (see LICENSE).

It contains these third-party items:

- **Icons**: Font Awesome Free, icons licensed CC BY 4.0 (https://fontawesome.com/license/free). Inlined in `popup/icons.js`.
- **Breach list** (`src/breaches.js`): the names of websites with public data breaches, from Have I Been Pwned, licensed CC BY 4.0 (https://haveibeenpwned.com/). Contains no personal data.
- **Password lookup**: when the optional password check is on, the first 5 characters of a password hash are sent to the Pwned Passwords range service (https://haveibeenpwned.com/API/v3#PwnedPasswords).

The tracker list (`data/lists.json`) and the company names (`data/companies.json`) were compiled by VPNInsights. No code or lists were copied from other blockers.
